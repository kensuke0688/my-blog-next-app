コードレビューをお願いします。

# レビューのルール

- 修正後のコードを丸ごと書かないでください。「どこが」「なぜダメか」「どう直すかの方針」だけを伝え、修正は私にやらせてください。
- 下のチェックリストを上から順に確認してください。1〜3が未達の場合は、そこだけを指摘し、4以降には触れないでください。
- 指摘は一度に最大3件までにしてください。多すぎると直しきれません。
- 全項目を満たしていたら「LGTM(合格)」と伝えてください。忖度して甘く判定しないでください。
- 最後に、私が次に何をすべきかを1行で書いてください。

# チェックリスト

1. 追加した機能が正しく動作すること
2. PRの説明に「AIにどう指示したか」が書かれていること。プロンプトが「いい感じにして」のような曖昧なものになっていないこと
3. AIが生成したまま残っている不要なコード・コメント・使われていない関数がないこと
4. CLAUDE.md に、このプロジェクト固有のルール(使う技術・命名規則・やってほしくないこと)が書かれていること。どのプロジェクトにも当てはまる一般論だけになっていないこと
5. .claude/settings.json に、deny ルールか Hooks が1つ以上設定されていること
6. 自作Skillが、実際に繰り返し使う作業を対象にしていること(一度しか使わない作業をSkill化していないこと)
7. MCP接続が実際に動作していること
8. コミットが作業単位で分かれ、メッセージから何をしたか分かること

# レビュー対象

次のものを順に読んでください。

- 私が添付した差分のテキスト … 今回追加した機能(チェックリスト1〜3)
- 私が添付したPRの説明文 … チェックリスト2
- 私が添付したコミット一覧 … 作業単位とメッセージ(チェックリスト8)
- リポジトリ直下の `CLAUDE.md`、`.claude/settings.json`、`.claude/skills/` 配下、`.mcp.json` … 4点セット(チェックリスト4〜7)

最後に、私のCLAUDE.mdを読んで、「この一行があると、次から手戻りが減る」という追記案を1つだけ提案してください。
